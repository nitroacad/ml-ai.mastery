02. Modern Python Environments & Tooling

🎯 Learning Outcomes

  • Build lightning-fast virtual environments using uv (10-100x faster than standard pip/conda).
  • Understand pyproject.toml and deterministic lockfiles (uv.lock).
  • Configure Jupyter kernel management linked directly to active virtual environments.

Why It Matters

"It worked on my local machine" is the primary cause of model deployment failures. Differing package versions (e.g., PyTorch 2.0 vs 2.1) alter model execution behavior or C++ CUDA bindings. Deterministic environment setup is mandatory for high-velocity machine learning production teams.

The Shift to Blazing-Fast Python Tooling: uv

Historically, Python developers relied on virtualenv, pip, or conda. Modern ML engineering uses uv—an extremely fast Python package installer and resolver written in Rust. It serves as a drop-in replacement for pip and virtualenv while automatically managing underlying Python interpreter binaries.

Hands-on Code: Setting Up an ML Project with uv

BASH 
# Install uv
curl -LsSf https://astral.sh/uv/install.sh | sh

# Create a new ML project directory
uv init my-ml-service
cd my-ml-service

# Create and activate a virtual environment with Python 3.11
uv venv --python 3.11
source .venv/bin/activate

# Add core ML dependencies (installs and updates pyproject.toml automatically)
uv add numpy pandas scikit-learn torch

# Run a script deterministically
uv run python main.py

⚠️ Common Mistake

Installing packages globally into the system Python environment (/usr/bin/python). This pollutes system libraries and causes dependency conflicts across projects.

🚀 Production Tip

Always commit your lockfile (e.g., uv.lock or requirements.txt pinned with exact hashes) into Git. Never use unpinned dependencies in production Docker images.

Self-Check Quiz

What is the main advantage of using lockfiles like uv.lock in a machine learning repository?

They speed up Python code execution at runtime.
They compile Python code into C++ binaries.
They guarantee exact, deterministic dependency resolution across all developer machines and CI/CD pipelines.
They automatically convert Jupyter notebooks into REST APIs.
