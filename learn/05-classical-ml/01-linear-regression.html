01. Linear Regression & Gradient Descent

🎯 Learning Outcomes

  • Formulate Linear Regression mathematically using matrix equations: $\hat{y} = X\mathbf{w} + b$.
  • Derive Ordinary Least Squares (OLS) closed-form solution and Mean Squared Error (MSE) gradients.
  • Implement Gradient Descent from scratch in NumPy and using Scikit-Learn.

Why It Matters

Linear regression is the foundation of predictive modeling and statistical inference. Deep neural networks are essentially stacked non-linear transformations built on linear operations ($W^TX + b$). Understanding gradient descent optimization on linear systems is vital for debugging complex neural nets.

Mathematical Formulation

Given a dataset of $N$ samples with $D$ features, linear regression models the target $y$ as a linear combination of inputs:

ŷ = w₁x₁ + w₂x₂ + ... + w_D x_D + b

We measure error using Mean Squared Error (MSE):

MSE = (1 / N) * Σ (y_i - ŷ_i)²

⚠️ Common Mistake

Failing to scale input features (standardization/min-max) before applying gradient descent. Unscaled features cause elongated loss contours and oscillating learning curves.

🚀 Production Tip

In production, use Ridge ($L_2$) or Lasso ($L_1$) regularization when feature correlation (multicollinearity) is present to prevent wildly unstable weight coefficients.

Self-Check Quiz

What happens if the learning rate ($\alpha$) in Gradient Descent is set too high?

The model converges instantly to the global minimum.
The optimization process diverges or jumps over the local minimum.
The model automatically switches to Lasso regularization.
The gradient vector reduces to zero.
