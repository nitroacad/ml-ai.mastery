02. Decision Trees, Random Forests & XGBoost

🎯 Learning Outcomes

  • Calculate Gini Impurity and Entropy for decision tree node splitting.
  • Distinguish Bagging (Bootstrap Aggregating in Random Forests) from Boosting (Gradient Boosting).
  • Train and tune Random Forests and Gradient Boosted Trees using Scikit-Learn.

Why It Matters

Tree ensemble methods (Random Forest, XGBoost, LightGBM) dominate tabular data competitions and production systems. They handle non-linear feature interactions out of the box, require minimal feature scaling, and provide high predictive performance with robust default parameters.

Decision Trees & Split Criteria

A decision tree splits data recursively into binary branches. For classification, Gini Impurity measures node randomness:

Gini = 1 - Σ (p_i)²

Bagging vs Boosting

  • Bagging (Random Forest): Trains multiple decision trees in parallel on random bootstrap subsets of data and feature subsamples. Reduces model variance.
  • Boosting (XGBoost/LightGBM): Trains decision trees sequentially. Each new tree fits on the residual errors (pseudo-residuals) of prior trees. Reduces model bias.

⚠️ Common Mistake

Allowing a single decision tree to grow without a max_depth restriction, leading to severe overfitting where every training leaf contains a single sample.

🚀 Production Tip

Use LightGBM or CatBoost when dealing with millions of tabular rows or high-cardinality categorical features; both run significantly faster than standard Scikit-Learn ensembles.

Self-Check Quiz

How does Gradient Boosting differ fundamentally from Random Forest bagging?

Gradient Boosting builds trees independently in parallel.
Gradient Boosting uses deep unpruned trees to maximize variance.
Gradient Boosting builds trees sequentially, with each new tree attempting to correct residual errors from previous trees.
Gradient Boosting eliminates the need for target labels.
