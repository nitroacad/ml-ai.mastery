Module 05

Classical Machine Learning

Master supervised and unsupervised learning algorithms that power the majority of production tabular systems worldwide.

📌 Module Overview & Outcomes

  • Implement Linear & Logistic Regression from raw mathematical principles and using Scikit-Learn.
  • Understand decision boundary splitting, Gini impurity, and Entropy for Tree models.
  • Master ensemble methods: Bagging (Random Forests) vs Boosting (XGBoost, LightGBM, CatBoost).
  • Apply dimensionality reduction (PCA, t-SNE) and unsupervised clustering (k-Means, DBSCAN).

Lessons in this Module

01. Linear Regression & Gradient Descent

Mathematical formulation, Ordinary Least Squares (OLS), loss functions, and optimization.

02. Decision Trees, Random Forests & XGBoost

Recursive binary splitting, variance reduction via bagging, and gradient boosting mechanisms.
